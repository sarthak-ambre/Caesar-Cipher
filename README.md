# 🔐 Caesar Cipher - Encoder & Decoder

A simple secret message encoder and decoder built with Python.

## 💡 What it does
- **Encode** your message into a secret code
- **Decode** the secret code back to original message
- Uses Caesar Cipher — shifts each letter by 3 positions

## 🚀 How to use
1. Run the program
2. Type `encoder` to encode a message
3. Type `decoder` to decode a message
4. Type your message and get the result

## 🔧 Built with
- Python 3
- Core concepts: loops, functions, ASCII values, string manipulation
